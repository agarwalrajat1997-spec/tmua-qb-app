Independent exact JSON loaders and a standalone validator use the agreed 2026 blueprint; no Physics-bank files or bank question schema are imported by the new model/loader/runner. New SL Paper 2 is 50 marks. The student prompt and submitted-solution allowlists exclude all source anchors, change notes, verification and internal cognitive-demand metadata.

Routes remain `/ib/mocks/<set>/<paper>` and `/api/ib/mocks/<set>`. The new `ib_physics_challenge_attempts` table isolates new submissions. Names, answers, elapsed time and the first written self-assessment are immutable. Both API methods check verified sign-in and current IB access before private question loading or attempt operations. Current trial-required, expired and unavailable states fail closed. MCQs are automatically scored; totals remain pending until every written part has a bounded integer self-mark.

The wall-clock timer survives refresh, account/paper/version draft keys isolate saved work, and a failed submission keeps responses locked on the device for retry. The server returns the first submission on duplicate attempt IDs. EmailJS completion and scored reports have separate persisted browser delivery states and manual retry; page refresh does not resend accepted reports. Completion reports clearly identify pending written marks. Both emails, the new-tab link and the lazily opened PDF iframe use exactly `/ib-mock-solutions/<paper-id>.pdf`.
